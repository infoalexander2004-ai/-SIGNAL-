## Об игре

«СИГНАЛ» — минималистичный аркадный шутер «Vampire Survivors»-лайк: короткие забеги,
мгновенный старт, никакого сюжета — только чистый геймплей и «ещё один забег».

**Ключевые особенности:**

- 🕹️ **Арена-выживание** — волны врагов нарастают, поле сужается, выживание — единственная цель.
- 🎲 **Roguelike-прогрессия** — каждый уровень даёт выбор 1 из 3 случайных улучшений, забеги всегда разные.
- ⚡ **Минимализм и неон** — процедурно отрисованные 2D-спрайты, частицы, тряска экрана. Без внешних ассетов.
- 🔊 **Программный звук** — все эффекты генерируются на старте, никаких аудиофайлов.
- 📦 **Один .exe ~0.9 МБ** — без установки, интернета и зависимостей. Работает на любом ПК с Windows 7+.
- 🏆 **Таблица рекордов** — топ-10 результатов сохраняется локально.

**Технологии:** C++17, WinAPI + GDI, двойная буферизация, фиксированный игровой таймер ~60 FPS, `std::mt19937` для псевдослучайности.

## Геймплей

```
Выживай на арене → Уничтожай врагов → Собирай дата-ядра → Прокачивайся (выбор 1 из 3)
   → Каждая волна сильнее → Рекорд растёт → Смерть → Начать заново (новые случайные улучшения)
```

- Арена — прямоугольник с неоновой рамкой; рамка меняет цвет по мере роста волны.
- Игрок автоматически стреляет в сторону курсора при зажатой ЛКМ.
- С врагов выпадают **дата-ядра** (опыт), которые притягиваются магнитом.
- При заполнении шкалы опыта игра ставится на паузу — выберите улучшение.
- **Особая способность «Перезагрузка»** (клавиша `E`) мгновенно уничтожает всех врагов на экране.
- Каждые 5 волн появляется **БОСС** — огромный красно-фиолетовый «КРАКЕН».

### Экранные эффекты

- Тряска экрана при взрывах и уроне.
- Вспышки при попаданиях и получении урона.
- Неоновая подсветка, частицы взрывов, след игрока.
- Иконки кулдаунов и расходников в HUD.

## Управление

| Клавиша | Действие |
|---|---|
| `W` / `A` / `S` / `D` или `↑←↓→` | Движение |
| `Мышь` | Прицеливание |
| `ЛКМ` (удерживать) | Автоматическая стрельба |
| `Пробел` | Рывок (dash), кулдаун 2 сек |
| `E` | «Перезагрузка» — уничтожить всех врагов, кулдаун 15 сек |
| `Q` | Замедление времени на 3 сек, кулдаун 20 сек |
| `1` / `2` / `3` | Расходники (аптечка / щит / бомба) |
| `P` / `Esc` | Пауза |
| `R` | Перезапустить забег (на экране смерти) |
| `Enter` | Подтверждение |
| `F` | Полноэкранный режим |
| `M` | Звук вкл/выкл |
| `Esc` (в меню) | Выход |

> Диагональное движение нормализуется: скорость одинакова в любом направлении.

## Враги

| Враг | HP | Скорость | Урон | Поведение | Очки |
|---|---|---|---|---|---|
| **Вирус** (красный) | 1 | средняя | 10 | Летит прямо на игрока | 10 |
| **Ботнет** (оранжевый) | 1 | высокая | 6 | Быстрый, мелкий, роится | 15 |
| **Спамер** (зелёный) | 3 | низкая | 8 | Держит дистанцию, стреляет | 25 |
| **Танк** (пурпурный) | 8 | низкая | 20 | Медленный, толстый | 50 |
| **Прокси** (серый) | 2 | высокая | 25 | Взрывается рядом с игроком | 30 |
| **БОСС «КРАКЕН»** | 60 | средняя | 30 | Каждые 5 волн, веер снарядов | 500 |

HP и скорость врагов растут от сложности и номера волны. Спамер стреляет снарядами,
которые можно сбивать собственными пулями.

## Сборка из исходника

Требуется **Windows** и один из компиляторов:

### Вариант 1 — готовый скрипт

Запустите `build.bat` рядом с `signal.cpp`. На выходе — `signal.exe`.

### Вариант 2 — MinGW (g++)

```cmd
g++ -O2 -Wall -finput-charset=utf-8 -std=c++17 -mwindows -static ^
    -o signal.exe signal.cpp -lgdi32 -lwinmm -lmsimg32
```

### Вариант 3 — MSVC

```cmd
cl /O2 /EHsc /std:c++17 /utf-8 signal.cpp user32.lib gdi32.lib winmm.lib msimg32.lib /link /SUBSYSTEM:WINDOWS /OUT:signal.exe
```

После сборки просто запустите `signal.exe` — игра не требует установки.

## Файлы сохранений

Файлы создаются рядом с `signal.exe`:

| Файл | Содержимое |
|---|---|
| `signal_scores.dat` | Рекорды (до 10): очки, волна, дата |
| `signal_settings.dat` | Настройки: сложность, громкость, звук, фулскрин, авто-прицел |

Файлы текстовые, при повреждении пересоздаются автоматически.
